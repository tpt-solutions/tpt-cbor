# Code of conduct

Participants in this project are expected to treat each other with respect.
Discussion should stay on the technical merits: be constructive, assume good
faith, and keep comments about the work rather than about people.

Unacceptable behaviour includes harassment or insults, personal or political
attacks, publishing someone's private information without consent, and any
conduct that a reasonable person would find hostile in a professional setting.

Report concerns through GitHub's private channels for this repository. The
maintainers (TPT Solutions) will review each report, act in proportion to it,
and keep the reporter's identity confidential where that is possible.

This document is a summary. The project follows the principles of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which applies where this summary is silent.
